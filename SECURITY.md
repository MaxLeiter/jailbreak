# Security Policy

Please do not report sensitive issues in a public issue.

Use GitHub private vulnerability reporting if it is enabled for the repository. If it is not available, contact the maintainer privately before publishing details.

Security-sensitive examples include leaked keys or tokens, package signing problems, repository-publish flaws, install paths that unexpectedly escape the rootless prefix, and bugs that create new device compromise risk beyond the jailbreak environment itself.

This project targets jailbroken devices, so not every jailbreak-related behavior is a vulnerability in this repository. Reports are most useful when they identify a specific repo-controlled bug, affected files, expected impact, and a minimal reproduction path.
