Gnumeric

Desktop spreadsheets on a jailbroken iPad

Gnumeric is a full desktop spreadsheet running locally on a jailbroken iPad through xiOS.

  • Worksheets, formulas, formatting, and charts
  • Common workbook import and export support
  • GTK3 desktop interface with touch, pointer, and keyboard input

A compatible rootless jailbreak and xiOS desktop session are required.
