AutoLockPicker

Set any Auto-Lock time with a picker

Replace the stock Auto-Lock list — which caps at 15 minutes — in Settings → Display & Brightness → Auto-Lock with a real time picker.

  • Pick any duration (minutes or hours) with a countdown wheel
  • A Never switch to disable auto-lock entirely
  • Writes the same ManagedConfiguration value iOS itself uses, so it's enforced exactly like a built-in setting — no respring needed
  • The Display & Brightness row updates to show your custom value

Built for iPadOS 17, rootless (palera1n).
