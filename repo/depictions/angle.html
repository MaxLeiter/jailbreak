ANGLE (GLES via Metal)

Hardware OpenGL ES via ANGLE on Metal

ANGLE (Almost Native Graphics Layer Engine) built for jailbroken iOS, translating OpenGL ES to Metal so X11 and GTK apps can use the GPU.

Provides `libEGL` and `libGLESv2` under a private prefix (`/var/jb/lib/angle`) so they sit alongside the Mesa software renderer with no conflict. Verified on-device on the A10 GPU, including `EGL_ANGLE_iosurface_client_buffer` for zero-copy rendering into shared IOSurfaces.

  • Real GPU acceleration (Metal backend) for GLES2 and GLES3
  • EGL 1.5 with IOSurface client buffers
  • Coexists with the software GL stack

GPU-using apps must be signed with the appropriate GPU entitlements. Built for iPadOS/iOS rootless (palera1n/Dopamine, `/var/jb`).
