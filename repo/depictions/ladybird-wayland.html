Ladybird (Wayland)

The Ladybird browser for Xios desktop sessions

Ladybird is a new web browser with its own engine, written from scratch rather than built on WebKit or Chromium. This is the desktop build, which runs locally as a window inside a xiOS session.

It adds a normal application entry and opens through whichever desktop you are running. A compatible rootless jailbreak is required.

If you want a Home Screen browser icon instead, install Ladybird (ladybird-app).
