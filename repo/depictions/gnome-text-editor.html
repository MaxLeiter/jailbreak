gnome-text-editor

GNOME Text Editor, simple and modern

GNOME Text Editor running natively on your jailbroken device through the X11-on-iOS stack. The default GNOME editor: clean and fast, built on GTK4 and libadwaita, with syntax highlighting from GtkSourceView.

Runs as a real native arm64 binary. Renders into the Xios display server and uses San Francisco by default when the `x11-fonts-sf` package is installed.

  • Syntax highlighting for common languages (GtkSourceView 5)
  • Session restore, split view, and dark mode
  • libadwaita styling

Built for iPadOS/iOS rootless (palera1n/Dopamine, `/var/jb`).
