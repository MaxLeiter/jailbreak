Thunar

The Xfce file manager, running on iPad

Thunar is the Xfce desktop file manager, rebuilt for arm64 iOS and running through xiOS.

  • Icon and list views with normal desktop file operations
  • Path navigation and access to the mobile home directory
  • Runs inside a xiOS desktop or an individual iPadOS host window

A compatible rootless jailbreak is required.
