dunst, a lightweight notification daemon

dunst is a lightweight, customizable notification daemon for the iosc Wayland compositor.

It implements the freedesktop notification specification over D-Bus, so apps that post notifications get clean on-screen popups rendered through Pango and Cairo.

  • freedesktop notifications over D-Bus
  • Native Wayland via the wlr layer-shell protocol
  • Pango and Cairo rendering with full styling control
  • Rules to filter, group, and route notifications

Run it inside an Xios desktop session running the iosc compositor.
