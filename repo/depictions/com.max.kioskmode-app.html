Kiosk Mode

Lock the iPad to a single app

Kiosk Mode locks your iPad (or iPhone) to a single app and relaunches it automatically, turning a device into a single-purpose kiosk.

This is the setup app: pick the target app and manage the kiosk settings from a simple onboarding flow. The lock and auto-relaunch behavior lives in the companion SpringBoard tweak (KioskMode, package com.max.kioskmode); install both for the full feature.

  • Choose any installed app to lock to
  • Auto-relaunch if the app is closed
  • Escape a locked session with a volume-button triple-press

Requires iOS/iPadOS 17+ and AppSync Unified to run the setup app.
