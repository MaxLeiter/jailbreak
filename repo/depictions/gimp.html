GIMP

GIMP 3.2, running locally on a jailbroken iPad

GIMP 3.2 for iOS is the full desktop image editor rebuilt for arm64 iOS and running locally through xiOS. It is not a remote desktop, web wrapper, or App Store impersonator.

  • Standard GIMP toolbox, docks, layers, filters, and color tools
  • Bundled brushes, plug-ins, and image-format support
  • GTK3 desktop interface rendered through Wayland and Metal
  • Touch, pointer, and hardware-keyboard input through xiOS

A compatible rootless jailbreak and a xiOS desktop flavor are required. Install gimp-native as well if you want a Home Screen launcher and individual iPadOS host window.
