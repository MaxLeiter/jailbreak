libmozjs-115-0

SpiderMonkey JavaScript engine (mozjs 115)

SpiderMonkey (mozjs 115 ESR) is Mozilla's JavaScript engine for the GNOME stack. gjs and GNOME Shell build on it, so it is the foundation for GNOME's JavaScript applications.

This package is the interpreter-only build, which runs anywhere. There is also a JIT build, which is much faster but needs the dynamic-codesigning entitlement on whatever embeds it.

  • libmozjs-115-0: the runtime engine
  • libmozjs-115-dev: headers and static library, for building gjs and other embedders
  • libmozjs-115-jit-0: the JIT build, a drop-in replacement for the runtime engine

A build and runtime dependency for the GNOME JavaScript stack.
