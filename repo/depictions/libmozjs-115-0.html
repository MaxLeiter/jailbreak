libmozjs-115-0

SpiderMonkey JavaScript engine (mozjs 115)

SpiderMonkey (mozjs 115 ESR), Mozilla's JavaScript engine, cross-compiled for jailbroken iOS. This is the JS runtime that gjs and GNOME Shell build on, so it is the foundation for running GNOME's JavaScript applications natively.

Built JIT-less (interpreter only), since iOS does not permit runtime-writable executable memory. The engine is a native arm64 Mach-O with full Intl/ICU support.

  • `libmozjs-115-0`: the runtime engine
  • `libmozjs-115-dev`: headers + static library, for building gjs and other embedders

A build and runtime dependency for the GNOME JavaScript stack. Built for iPadOS/iOS rootless (palera1n/Dopamine, `/var/jb`).
